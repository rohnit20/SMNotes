## 🗂️ Topics Covered

### Module 1 — Fundamentals & Levels of Strategy
- Planning vs. Strategy (W's vs. How)
- Mintzberg's 5 Ps (Plan · Ploy · Pattern · Position · Perspective)
- Vision · Mission · Objectives · Strategic Intent hierarchy
- Strategic Management Process (4 phases)
- Four levels of strategy (Corporate → SBU → Functional → Operational)
- Corporate Strategy Tree (Growth / Stability / Retrenchment + all sub-types)
- SpiceJet Turnaround Case
- CSR: Carroll's Pyramid, Triple Bottom Line, Strategic CSR, CSV, Companies Act 2013 S.135

### Module 2 — Environmental Analysis Tools
- PESTEL Framework
- Porter's Five Forces + 6th Force (Complementors — Brandenburger & Nalebuff 1996)
- Value Chain Analysis (Porter, 1985)
- SWOT / TOWS Matrix
- Scenario Analysis (Shell case)
- VUCA World + **VUCA–RBV connection** (professor-flagged exam question)
- Resource-Based View (RBV) — Heterogeneous + Immobile properties
- VRIO Framework (Barney, 1991)
- Red Ocean vs. Blue Ocean + ERRC Framework

### Module 3 — Portfolio & Competitive Strategy Tools
- BCG Matrix (Henderson, 1970s) + linkage to Product Life Cycle
- GE-McKinsey Nine Cell Matrix
- **BCG vs. GE Comparison** (professor-flagged exam question)
- Ansoff Matrix (Igor Ansoff, 1957) — Growth directions + Risk profiling
- Grand Strategy Matrix (4 quadrants)
- Porter's Generic Strategies + "Stuck in the Middle" + BrewBean Café case
